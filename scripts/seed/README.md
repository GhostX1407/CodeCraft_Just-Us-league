# Database Seed & Fixture Scripts

This directory is designated for database population, scenario fixtures, and seed data scripts (e.g. realistic hospital capability sets, demo trauma cases, mass casualty incident templates) to be implemented in Phase 4 (Firestore & Backend Services).

## Planned Fixtures
- Seed hospitals with diverse capabilities, ICU counts, and trauma levels
- Realistic geographic coordinates and baseline ER load scores
- Test case scenarios (Scenario A: Single acute patient matching & acceptance, Scenario B: Timeout & auto-reroute, Scenario C: Mass casualty event)
